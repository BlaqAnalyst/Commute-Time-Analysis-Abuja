# 🚗 Commute Time Analysis – Abuja

## 📊 Data Analyst Portfolio Project

> An end-to-end data analysis project exploring Abuja's commuting patterns, transportation costs, traffic conditions, and transport-mode usage using Python, Pandas, Excel, and Power BI.

---

## 🎯 Project Objectives

This project analyzes 250 Abuja commute records to understand:

- Commute duration
- Transportation costs
- Traffic conditions
- Transport-mode usage
- Commuting patterns

The project demonstrates a complete data analytics workflow from data cleaning to visualization and dashboard development.

This visualization shows the distribution of transportation modes in the dataset.

📈 Transport Mode Frequency

This analysis shows how frequently each transport mode appears in the dataset.
