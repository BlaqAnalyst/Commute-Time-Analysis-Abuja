## Project Overview

This project analyses 250 Abuja commute records to understand commuting patterns, commute duration, transportation fares, traffic conditions, weather, and transport-mode usage.

The workflow used Microsoft Excel for data preparation, Python/Pandas in Google Colab for data cleaning and descriptive analysis, and Microsoft Power BI for the final interactive dashboard.

## Key Findings

- Average commute time: **41.81 minutes**
- Average transportation fare: **₦3,175**
- Higher traffic levels were associated with longer commute times.
- Public buses were the most affordable transport option in the analysis.
- The Power BI dashboard provides KPI cards, comparative charts, transport-mode distribution, and interactive filters.
